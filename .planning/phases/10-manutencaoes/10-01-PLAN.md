## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API → Service | FormRequest validates input before reaching Service |
| Service → DB | Transactional writes prevent partial state |
| User → Controller | Sanctum auth + static permission middleware |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-01 | Tampering | MaintenanceService::complete() status transition | high | mitigate | `MaintenanceStatus::canTransitionTo()` validates every transition; throws MaintenanceException on invalid |
| T-10-02 | Tampering | Mass assignment via update() | medium | mitigate | Model `$fillable` whitelist restricts writable columns; `updated_by` manually set in controller |
| T-10-03 | Information Disclosure | IDOR via maintenance_order_id in URL | medium | mitigate | Controller uses `permission:manutencoes.view` gate — all orders viewable by authorized users; fine-grained policies deferred to future phase |
| T-10-04 | Repudiation | Soft-delete without audit | medium | mitigate | `LogsActivity` trait on model + `$auditExclude` for updated_by/deleted_by |

</threat_model>
