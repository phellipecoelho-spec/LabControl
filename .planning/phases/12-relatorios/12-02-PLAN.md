```typescript
export const reportService = {
  async getReportList(): Promise<ReportListResponse> {
    return api.get('/reports').then(r => r.data)
  },
  
  getDownloadUrl(type: ReportType, format: ReportFormat, filters?: ReportFilters): string {
    const params = new URLSearchParams({ format })
    if (filters?.date_from) params.append('date_from', filters.date_from)
    if (filters?.date_to) params.append('date_to', filters.date_to)
    if (filters?.status) params.append('status', filters.status)
    return `/api/v1/reports/${type}?${params}`
  }
}
```
</action>

## Risks

| Risk | Likelihood | Mitigation |
|------|-----------|------------|
| Large file download timeout | Low | Backend generates files within reasonable time; timeout config in axios |
| Browser blocks download popup | Low | Direct download via anchor click (not window.open) |
| Network error mid-download | Low | Error handling with toast message; user can retry |
| Memory issues with large XLSX/CSV | Low | Dataset sizes are laboratory-scale; streaming on backend side |

## Edge Cases

| Case | Handling |
|------|----------|
| Empty report results | Valid empty file is downloaded (not an error) |
| Network timeout | Toast error: "Tempo limite excedido. Tente novamente." |
| Server error (500) | Toast error: "Erro ao gerar relatório. Tente novamente." |
| Permission denied (403) | Toast error: "Você não tem permissão para exportar relatórios." |
| User clicks multiple times | Button shows loading spinner, disables during download |
| All filters empty | Downloads all records (backed handles this) |
| Invalid date range | Backend validation returns 422; frontend shows validation errors |
| Concurrent downloads | Each button has independent loading state; multiple downloads work simultaneously |
