<task id="12-01-02" status="pending">
<description>Create ReportService with all report generation methods</description>
<read_first>
- backend/app/Services/DashboardService.php
- backend/app/Services/CalibrationCertificateService.php
- .planning/phases/12-relatorios/12-RESEARCH.md (report schemas section)
</read_first>
<action>
Create `backend/app/Services/ReportService.php` with methods for each report type:
- equipmentsReport(array $filters): StreamedResponse
- calibrationsReport(array $filters): StreamedResponse
- inventoryMovementsReport(array $filters): StreamedResponse
- dashboardExport(array $filters): StreamedResponse

Each method:
1. Applies filters (date range, status) to the Eloquent query
2. Determines format from $filters['format'] (pdf|xlsx|csv)
3. Returns appropriate response:
   - PDF: Stream PDF from DomPDF facade (stream the Blade view)
   - XLSX: Return Excel download from Laravel Excel facade
   - CSV: Return streamed CSV using response()->streamDownload() + fputcsv
</action>
<acceptance_criteria>
- ReportService has 4 public methods matching the 4 report types
- Each method accepts array $filters and returns StreamedResponse or BinaryFileResponse
- PDF uses DomPDF stream method
- XLSX uses Laravel Excel download method
- CSV uses response()->streamDownload() with fputcsv
- CSV output prepends UTF-8 BOM bytes \xEF\xBB\xBF for Excel compatibility
- All methods apply period filter (created_at range) when provided
- All methods apply status filter when provided
- Empty results return valid empty file (not an error)
</acceptance_criteria>
<subtasks>
  - Create service class in App\Services namespace
  - Implement equipmentsReport: query Equipment with relationships, format PDF/XLSX/CSV
  - Implement calibrationsReport: query Calibration with equipment, format PDF/XLSX/CSV
  - Implement inventoryMovementsReport: query InventoryMovement with item, format PDF/XLSX/CSV
  - Implement dashboardExport: reuse DashboardService KPIs + chart data, format CSV/XLSX only
  - Share filter logic via private method buildFilters()
  - Add docblocks with @throws for invalid format
</subtasks>
</task>

<action>
Create `ReportController.php`:
- Implement `Illuminate\Routing\Controllers\HasMiddleware`
- Static middleware(): auth:sanctum for all, permission:relatorios.view for index, permission:relatorios.export for download
- `index()`: Return list of available report types with metadata (name, description, formats)
- `download(string $type, ReportRequest $request)`: Validate type and format, delegate to ReportService, return StreamedResponse

Create `ReportRequest.php`:
- Validate format (pdf, xlsx, csv)
- Validate date_from/date_to if provided (dates, date_from <= date_to)
- Validate status if provided (string)

Register routes in api.php:
```php
Route::prefix('reports')->middleware('auth:sanctum')->group(function () {
    Route::get('/', [ReportController::class, 'index'])->middleware('permission:relatorios.view')->name('reports.index');
    Route::get('{type}', [ReportController::class, 'download'])->middleware('permission:relatorios.export')->name('reports.download');
});
```
</action>
<acceptance_criteria>
- ReportController implements HasMiddleware with static middleware()
- index() returns list of report types with metadata
- download() validates type against ['equipments', 'calibrations', 'inventory-movements', 'dashboard']
- download() validates format against ['pdf', 'xlsx', 'csv']
- ReportRequest validates dates and status
- Routes registered under auth:sanctum group with permission middleware
- Returns 403 for unauthorized access
- Returns 422 for invalid filters
- Returns 400 for invalid format
</acceptance_criteria>

## must_haves

### truths
- Backend generates PDF files from Blade views via DomPDF
- Backend generates XLSX files via Laravel Excel
- Backend generates CSV files via StreamedResponse + fputcsv
- All 4 report types are accessible (equipments, calibrations, inventory-movements, dashboard)
- CSV output includes UTF-8 BOM for Excel compatibility
- Routes require auth:sanctum and permission:relatorios.export
- Invalid format returns 400, not a crash
- Empty result set returns valid empty file (not 500)

### tests
- Feature tests verify auth bypass is impossible
- Feature tests verify permission enforcement
- Feature tests verify filter application
- Unit tests verify service method signatures
- File type tests verify Content-Type headers

## Risks

| Risk | Likelihood | Mitigation |
|------|-----------|------------|
| DomPDF CSS rendering differences | Medium | Test visually; use simple table layouts |
| Large dataset memory exhaustion | Low | Apply query limits; streaming for CSV |
| Excel file > 5MB | Low | Not expected for laboratory data volumes |
| Composer package conflicts | Low | Both packages support Laravel 13 (verified) |
