    - Query: Calibration com next_due_at entre $startDate e $endDate, GROUP BY month, ORDER BY month.
    - Retornar array de `{ month: string, scheduled: int, completed: int, due: int }`.
    - scheduled: COUNT onde status = 'scheduled'
    - completed: COUNT onde status = 'completed'
    - due: COUNT onde status = 'completed' AND next_due_at BETWEEN [now(), now()->addMonths(6)]
    - Usar `DB::raw()` ou `selectRaw()` com agregação SQL, sem N+1.

    - incoming: SUM(CASE WHEN type IN ('purchase', 'return') THEN quantity ELSE 0 END).
    - outgoing: SUM(CASE WHEN type IN ('consumption', 'adjustment', 'disposal') THEN quantity ELSE 0 END).
    - GROUP BY month, ORDER BY month.
    - Retornar array de `{ month: string, incoming: int, outgoing: int }`.
