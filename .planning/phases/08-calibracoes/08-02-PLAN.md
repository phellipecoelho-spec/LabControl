      - `auth:sanctum` on index, show, store, update, destroy, complete, cancel
      - `permission:calibracoes.view` on index, show
      - `permission:calibracoes.create` on store

      **`index(Request $request)`**: per D-15, D-16
      - Extract query params: equipment_id, status, from, to, laboratory
      - Query with with(['equipment:id,name,patrimony_id']) + when() chains for each filter
      - orderBy created_at desc, paginate(15)
      - Return new CalibrationCollection

      - load(['equipment', 'createdBy', 'certificates'])
      - Return new CalibrationResource

      **`store(StoreCalibrationRequest $request)`**:
      - Try: CalibrationService::create() → catch CalibrationException → 422
      - Return CalibrationResource with 201 status

      **`update(UpdateCalibrationRequest $request, Calibration $calibration)`**:
      - Guard: if status !== Scheduled → 422 "Apenas calibrações com status Agendada podem ser editadas."
      - Update with $request->validated(), set updated_by = auth()->id()
      - Load equipment relationship, return CalibrationResource

      **`destroy(Calibration $calibration)`**:
      - Set deleted_by = auth()->id(), save, delete (soft delete com auditoria)
      - Return 204

      **`complete(CompleteCalibrationRequest $request, Calibration $calibration)`**:
      - Try: CalibrationService::complete() → catch CalibrationException → 422
      - Load equipment, return CalibrationResource

      **`cancel(Request $request, Calibration $calibration)`**:
      - Try: CalibrationService::cancel() → catch CalibrationException → 422
      - Load equipment, return CalibrationResource

    - **`destroy(Calibration $calibration, string $certificate, CalibrationCertificateService $service)`**:
      - Call service->delete()
      - Return 204
