      - `async create(data)` → POST `/calibrations`
      - `async update(id, data)` → PUT `/calibrations/{id}`
      - `async delete(id)` → DELETE `/calibrations/{id}`

        - `async uploadCertificate(calibrationId, file: File)` → POST `/calibrations/{calibrationId}/certificates` com FormData + multipart header
        - `async deleteCertificate(calibrationId, certificateId)` → DELETE `/calibrations/{calibrationId}/certificates/{certificateId}`
